# ZTEX AEO

協助美國中小型品牌完成 AI 搜尋曝光、商品資料、購物結帳與第三方物流整合的一條龍代管服務。專案 owner：Tony Liu；目前階段：研究與付費試點設計。

## 從這裡開始

- [深度研究與商業建議](docs/research/2026-10-31-us-agentic-commerce.md)：定位、客群、平台、agent、物流、競爭與收費。
- [服務交付流程](docs/service-pipeline.md)：每個步驟的工作、產出與驗收。
- [90 天驗證計畫](docs/roadmap.md)：先驗證付費需求，再決定產品化。
- [官方來源與查證紀錄](docs/research/sources.md)：能力邊界、文件差異與待確認問題。
- [商家訪談與資料表](templates/merchant-intake.md)、[曝光實驗紀錄](templates/visibility-run.md)。

## 專案背景

[cloud.md](cloud.md) 是背景與決策的唯一主要版本；[CLAUDE.md](CLAUDE.md) 與 [AGENTS.md](AGENTS.md) 指向它。沿用使用者指定的 `cloud.md` 名稱。

第一階段以美國市場為準，服務 Shopify 商家優先，探索 WooCommerce、Wix、BigCommerce、Shopware 與 Stripe 管理式整合。只要提供產品、賣點、目標客戶，就能開始諮詢；實作仍需商家授權帳號、確認事實與營運政策。

## Repository 狀態

本機 Git 使用 `main` 分支；尚未指定或連結遠端。現階段是研究與服務設計 repository，尚無應用程式、部署環境或客戶實測數據。

機密、客戶原始資料、訂單與付款資訊不得放進 Git。可分享的研究與去識別化範本才放在此處。
